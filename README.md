## 🛠️ Troubleshooting

- Ensure the downloaded archive is named exactly **`WindowsPDFMergeSplitTool.zip`**.
- Extract it before running **`WindowsPDFMergeSplitTool.exe`**.

- A PDF fails to open: verify that the document is valid and is not restricted or corrupted.
- Output is missing: check the selected destination and write permissions.
- Page order looks wrong: review the input order or selected page ranges before exporting.
- **Download returns 404:** The release has not yet been published or its asset is not named `WindowsPDFMergeSplitTool.zip`.
